# Project Overview

## Purpose

The goal of this project is to design a serverless AWS pipeline that automates the processing of Aruba electronic invoice XML files and generates reminder emails before payment deadlines.

## Business Value

The solution reduces manual tracking of invoice due dates and supports a more reliable administrative workflow.

Potential benefits:

- less manual invoice monitoring
- lower risk of missed payment deadlines
- centralized invoice metadata
- automated reminder process
- scalable and low-maintenance architecture

## Target Users

This type of solution can support:

- finance teams
- administrative teams
- procurement teams
- operations teams
- small businesses handling electronic invoices

## Technical Goal

The project demonstrates how AWS managed services can be combined to build an event-driven data pipeline with minimal infrastructure management.
